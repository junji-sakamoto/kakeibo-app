# 画面3 カテゴリ一覧画面

[画面一覧と共通ルール](05-0_画面一覧と共通ルール.md) に戻る

## 1. 目的

カテゴリを種類ごとに確認し、カテゴリの登録・修正・削除を始める画面。

| 項目 | 内容 |
|---|---|
| 関係する機能 | 機能7（カテゴリの一覧）・機能9（カテゴリの削除） |
| ルール | [機能要件](04_機能要件.md) の「カテゴリの機能」 |

## 2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                                [記録] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  カテゴリ                                  [＋ 登録]   │
│                                                      │
│  ■ 支出用                                             │
│  ─────────────────────────────────────────            │
│  食費                              [修正] [削除]       │
│  外食                              [修正] [削除]       │
│  日用品                            [修正] [削除]       │
│  （…全部で12件）                                       │
│  その他                            [修正] [削除]       │
│                                                      │
│  ■ 収入用                                             │
│  ─────────────────────────────────────────            │
│  給料                              [修正] [削除]       │
│  賞与                              [修正] [削除]       │
│  （…全部で5件）                                        │
│  その他                            [修正] [削除]       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 3. 表示する項目

| 項目 | 内容 |
|---|---|
| 支出用のカテゴリ | 支出用のカテゴリの名前を、登録した順に並べる。ただし「その他」はいつも一番下（[機能要件](04_機能要件.md) の並び順のルール） |
| 収入用のカテゴリ | 収入用のカテゴリの名前を、登録した順に並べる。ただし「その他」はいつも一番下（[機能要件](04_機能要件.md) の並び順のルール） |

- ある種類のカテゴリが0件のとき：その種類の所に「カテゴリがありません。」（N03）と表示する

## 4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「＋ 登録」 | 画面4 カテゴリ入力画面を「登録」の状態で開く |
| 「修正」 | そのカテゴリの内容を入れた状態で、画面4 カテゴリ入力画面を「修正」の状態で開く |
| 「削除」 | 確認の窓（Q02）を出す。「削除する」なら削除して完了のメッセージ（I06）を出し、一覧を表示し直す。記録で使われているカテゴリのときは削除せず、「このカテゴリは記録で使われているため削除できません。」（E12）を出す |
