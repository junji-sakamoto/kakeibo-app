# 画面5 年間集計画面

[画面一覧と共通ルール](05-0_画面一覧と共通ルール.md) に戻る

## 1. 目的

選んだ年の収入・支出・差額の合計と、1月〜12月の月ごとの合計を確認する画面。どの月にお金が多く出入りしたかを、1年まとめて見られる。

| 項目 | 内容 |
|---|---|
| 関係する機能 | 機能10（年ごとの合計） |
| ルール | [機能要件](04_機能要件.md) の「年ごとの合計」 |
| 開き方 | 画面の上のメニューの「年間」を押す（今年を表示する） |

## 2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                         [記録] [年間] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│     [◀ 前の年]       2026年       [次の年 ▶] [今年]   │ ← ① 年の切り替え
│                                                      │
│  ┌──────────────┐ ┌──────────────┐ ┌──────────────┐   │
│  │ 収入          │ │ 支出          │ │ 差額          │   │ ← ② 年の合計
│  │ 3,000,000円  │ │ 2,160,000円  │ │ 840,000円    │   │
│  └──────────────┘ └──────────────┘ └──────────────┘   │
│                                                      │
│  年間                                                 │
│                                                      │
│  月        収入          支出          差額            │ ← ③ 月ごとの合計
│  ─────────────────────────────────────────────────── │
│  1月     250,000円     180,000円      70,000円        │
│  2月     250,000円     195,000円      55,000円        │
│  …                                                   │
│  12月          0円           0円           0円        │
│                                                      │
└──────────────────────────────────────────────────────┘
```

## 3. 表示する項目

| 番号 | 項目 | 内容 |
|---|---|---|
| ① | 表示中の年 | 「2026年」の形。最初は今年 |
| ② | 収入の合計 | 表示中の年の収入の合計 |
| ② | 支出の合計 | 表示中の年の支出の合計 |
| ② | 差額 | 収入の合計 − 支出の合計。マイナスのときは赤系の色にする |
| ③ | 月 | 「1月」〜「12月」。押すと、その月の記録一覧に移る |
| ③ | 収入 | その月の収入の合計。右にそろえる |
| ③ | 支出 | その月の支出の合計。右にそろえる |
| ③ | 差額 | その月の差額。右にそろえる。マイナスのときは赤系の色にする |

- 月ごとの合計は、記録が0件の月も含めて、**いつも1月〜12月の12行**を表示する（0件の月は「0円」）
- 収入・支出の見分けは、合計の枠と表の見出しの「収入」「支出」の文字で示す（色だけで伝えない）

## 4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「◀ 前の年」 | 1年前の合計を表示する。2000年を表示しているときは押せない |
| 「次の年 ▶」 | 1年後の合計を表示する。2099年を表示しているときは押せない |
| 「今年」 | 今年の合計を表示する |
| 月（「1月」〜「12月」） | 画面1 記録一覧画面に移り、その月の記録と合計を表示する |

- 表示中の年は、アドレス（`?year=2026`）に入れる。ブラウザの「戻る」で、前に見ていた年に戻れる
- 読み込み中・読み込めなかったときの表示は、[共通の表示ルール](05-0_画面一覧と共通ルール.md#4-共通の表示ルール) のとおり（読み込めなかったときは、合計を「－」とし、表の場所にメッセージと「読み込み直す」ボタンを出す）
