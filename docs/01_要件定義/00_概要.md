## 1. 概要

収入と支出を記録し、月ごとの合計を確認できる、ウェブブラウザで使う家計簿アプリを作る。
画面側（フロントエンド）・処理側（バックエンド）・データベースの3つの部品で作り、AWS に公開する。

## 2. 背景・目的

### 2-1. 背景

- スクールで、ウェブアプリの作り方（画面・処理・データベース・公開）を学んできた
- その学習のまとめとして、スクールから「**5つの候補の中から1つを選んで作り、提出する**」課題が出された
- ふだん、自分自身が家計簿ソフトを使っているので、「**自分でも作れるのだろうか**」と思い、5つの候補の中から**家計簿アプリ**を選んだ
- 課題には、使ってはいけない技術や公開先などの条件がある（くわしくは [課題の条件](01_課題の条件.md)）

### 2-2. 目的

このアプリを作る一番の目的は**学習**です。

| 番号 | 目的 | 具体的には |
|---|---|---|
| 1 | システム開発の流れを一通り経験する | 要件定義 → 設計 → 実装 → 試験 → 公開 を、資料を作りながら順番に進める |
| 2 | 3つの部品に分けて作る方法を身につける | 画面側・処理側・データベースを分けて作り、それぞれのつながり方を理解する |
| 3 | 授業で使った技術とは別の技術を、自分で調べて使えるようになる | 課題で使えない技術の代わりを、自分で選んで使う |
| 4 | インターネットに公開する方法を身につける | AWS の EC2 と RDS を使って、誰でも見られる状態で公開する |
| 5 | 実際に使える家計簿アプリを完成させる | 収入と支出を記録し、月ごとの合計を確認できる |

### 2-3. 達成できたと言える状態

- 講師が、公開したアドレスを開いて、すべての機能を試せる
- 講師が、GitHub で資料とプログラムを読んで、作った流れと仕組みが分かる

## 3. 作る範囲

### 3-1. 作るもの

| 区分 | 内容 |
|---|---|
| アプリ | 記録の登録・一覧・修正・削除、月ごとの合計、カテゴリの登録・一覧・修正・削除（くわしくは [機能一覧](03_機能一覧.md)） |
| 公開の環境 | AWS（EC2・RDS）での本番環境 |
| 資料 | 要件定義書、設計書、試験の資料、手順書（起動・公開・データの戻し方） |

### 3-2. 作らないもの

| 内容 | 作らない理由 |
|---|---|
| ログイン機能 | 使うのは自分1人で、講師が自由に試せるようにするため |
| カテゴリ別の集計・グラフ | 課題の範囲を絞るため（余裕があれば、あとで検討する） |
| 複数の人で家計簿を分ける機能 | 自分1人で使うため |
| データの書き出し・読み込み（CSV など） | 課題の範囲を絞るため |

## 4. 使う人

| 使う人 | 使い方 |
|---|---|
| 自分 | 開発中に、自分のパソコンで動かして使う |
| スクールの講師 | 提出後に、公開したアドレスを開いて機能を試す |

- 本番環境は**誰でも見られ、誰でも操作できる状態**で公開する
- そのため、本番環境には本物の家計のデータは入れず、**お試し用のデータだけ**を入れる

## 5. 前提条件（この要件定義書が成り立つための前提）

- 開発は自分1人で行う
- 提出期限は特にない
- 公開期間中の AWS の費用は、自分で支払う

守らなければいけない条件（制約条件）は [課題の条件](01_課題の条件.md) を参照してください。
