# 用語集

[要件定義書（入口）](00_要件定義書.md) に戻る

資料に出てくる専門用語を、五十音順（英字は最後）にまとめます。

| 用語 | 意味 |
|---|---|
| インターネット上の住所（アドレス・URL） | ウェブサイトの場所を表す文字列。例：`https://example.com` |
| 画面側（フロントエンド） | ブラウザに表示される画面や見た目の部分 |
| カテゴリ | 記録の分類。例：食費、交通費、給料 |
| 可用性 | 使いたいときに使える度合い |
| 控え（バックアップ） | トラブルに備えて、データを別の場所に写しておくこと |
| サーバー | インターネットの向こう側で動いているコンピューター。ここでは AWS の EC2 のこと |
| 処理側（バックエンド） | 画面から受け取ったデータを保存したり、集計したりする部分 |
| 制約条件 | 守らなければいけない条件 |
| 前提条件 | この資料の内容が成り立つための前提 |
| データベース | データを整理して保存しておく場所 |
| 遷移 | 画面が切り替わること |
| 本番環境 | 実際に人が使う、インターネットに公開した環境。反対は、自分のパソコンで動かす「開発環境」 |
| ブランチ | 作業の枝分かれ。本流（main）を壊さずに作業できる |
| ブラウザ | ウェブサイトを見るためのソフト。例：Google Chrome、Microsoft Edge、Safari |
| ヘッダー | 画面の一番上にある、アプリの名前やメニューを置く部分 |
| 問題の記録（ログ） | アプリが動いた記録や、起きた問題を書きためたもの |
| 要件定義 | 「何を作るか」を決めて、資料にまとめること |
| ライブラリ | 便利な機能をまとめた、他の人が作ったプログラムの部品 |
| AWS | Amazon が提供する、インターネット上のサーバーなどを借りられるサービス |
| CSV | 表のデータを、カンマで区切った文字で保存する形式 |
| EC2 | AWS で借りるサーバー（インターネット上のパソコンのようなもの） |
| GitHub | プログラムを保存・公開できるインターネット上のサービス |
| http / https | ブラウザとサーバーが通信するときの決まりごと。https は通信を暗号化するので、途中で盗み見られない |
| IPA | 情報処理推進機構。国の機関で、IT に関する指針を出している |
| RDS | AWS で借りるデータベース |
| SQL インジェクション | 入力欄に、データベースへの命令を入れて、データを盗んだり消したりする攻撃 |
| UTF-8 | 日本語を含む、世界中の文字を扱える文字の表し方（文字コード） |
| XSS（クロスサイト・スクリプティング） | 入力欄にプログラムを入れて、ほかの人の画面でそのプログラムを動かす攻撃 |
