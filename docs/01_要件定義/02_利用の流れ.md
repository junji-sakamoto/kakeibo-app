# 利用の流れ

[要件定義の概要（入口）](00_概要.md) に戻る

使う人が、どんな順番でアプリを操作するかをまとめます。
画面のくわしい内容は [画面要件](05-0_画面一覧と共通ルール.md)、画面のつながりは [画面遷移図](../02_設計/02_画面遷移図.md) を参照してください。

## 1. 毎日の記録

```
① アプリを開く
   → 「記録一覧画面」に、今月の記録と、今月の合計（収入・支出・差額）と、前月からの繰越・繰越後の残高が表示される
② 「登録」ボタンを押す → 「記録入力画面」に切り替わる
③ 日付・種類（収入／支出）・カテゴリ・金額・メモを入力して「保存」を押す
   → 「記録一覧画面」に戻り、一覧と合計に反映される
```

## 2. 記録の修正・削除

```
① 「記録一覧画面」で、直したい記録の「修正」または「削除」ボタンを押す
② 修正：「記録入力画面」で内容を直して「保存」を押す
   削除：「この記録を削除しますか？」で「削除する」を押す
   → 一覧と合計に反映される
```

## 3. 過去の月を見る

```
① 「記録一覧画面」で「◀ 前の月」「次の月 ▶」を押す
   → その月の記録と合計が表示される
```

## 4. カテゴリの管理

```
① 画面上の「カテゴリの設定」を押す → 「カテゴリ一覧画面」に切り替わる
② 「登録」「修正」→「カテゴリ入力画面」で入力して保存する
   「削除」→ 確認のあと削除する（記録で使われているカテゴリは削除できない）
   → 記録を入力するときの選択肢に反映される
```
