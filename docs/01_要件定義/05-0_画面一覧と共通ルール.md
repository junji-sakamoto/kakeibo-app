# 画面一覧と共通ルール

[要件定義書（入口）](00_要件定義書.md) に戻る

どんな画面があるかと、すべての画面に共通するルールをまとめます。
画面ごとのくわしい内容は、下の「画面の一覧」のリンクから開いてください。
ルールのくわしい内容は [機能要件](04_機能要件.md)、表示する文章は [メッセージ一覧](06_メッセージ一覧.md) を参照してください。

> 各画面の配置図は「どこに何があるか」を示すための簡単な絵です。色や大きさなどの細かい見た目は、設計で決めます。

## 1. 画面の一覧

| 番号 | 画面の名前 | 役割 | 関係する機能 |
|---|---|---|---|
| 画面1 | [記録一覧画面](05-1_記録一覧画面.md) | 最初に開く画面。月ごとの記録と合計を見る | 機能2・4・5 |
| 画面2 | [記録入力画面](05-2_記録入力画面.md) | 記録を登録・修正する | 機能1・3 |
| 画面3 | [カテゴリ一覧画面](05-3_カテゴリ一覧画面.md) | カテゴリを見る・削除する | 機能7・9 |
| 画面4 | [カテゴリ入力画面](05-4_カテゴリ入力画面.md) | カテゴリを登録・修正する | 機能6・8 |

- 登録と修正は、同じ入力画面を使う（見出しとボタンの文字だけを変える）
- 削除の確認は、画面ではなく小窓（ブラウザの確認ダイアログ）で行う

## 2. 画面のつながり（画面遷移）

画面のつながりは、設計の [画面遷移図](../02_設計/02_画面遷移図.md) にまとめています。

## 3. 画面の上の部分（ヘッダー）

すべての画面の一番上に表示します。

```
┌──────────────────────────────────────────┐
│ 家計簿                    [記録] [カテゴリ] │
└──────────────────────────────────────────┘
```

| 部品 | 動き |
|---|---|
| 「家計簿」（アプリの名前） | 押すと、画面1 記録一覧画面に移る |
| 「記録」 | 押すと、画面1 記録一覧画面に移る。画面1・2を開いているときは目立つ色にする |
| 「カテゴリ」 | 押すと、画面3 カテゴリ一覧画面に移る。画面3・4を開いているときは目立つ色にする |

## 4. 共通の表示ルール

| 内容 | ルール |
|---|---|
| 言葉 | 画面の文字・メッセージはすべて日本語 |
| 金額 | 3けたごとにカンマを付け、後ろに「円」を付ける（例：1,000円）。マイナスは「-1,000円」 |
| 日付 | 「2026年11月2日」の形で表示する。一覧では「11月2日（月）」のように曜日も付ける |
| 収入と支出の見分け | 収入は青系、支出は赤系の色にする。色が分かりにくい人のために、**必ず「収入」「支出」の文字も表示する** |
| 完了のお知らせ | 保存・削除が成功したら、画面の上に完了のメッセージを数秒間表示する |
| エラーのお知らせ | 入力の間違いは、その項目のすぐ下に赤い文字で表示する。通信の失敗などは画面の上に表示する |
| 読み込み中 | データを読み込んでいる間は「読み込み中…」（N04）と表示する |
| 二重の操作の防止 | 「保存」を押してから結果が出るまでは、ボタンを押せないようにする（同じ記録が2件できるのを防ぐ） |
| 存在しないページ | 「ページが見つかりません。」（S03）と表示し、記録一覧画面へのリンクを出す |
| 必須の項目 | 入力画面では、必須の項目に「＊」を付け、画面の下に「＊は必須の項目です」と書く |
