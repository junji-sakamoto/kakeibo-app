# 機能要件（機能に関する決まりごと）

[要件定義の概要（入口）](00_概要.md) に戻る

機能ごとのルールと、保存するデータをまとめます。
機能の一覧は [機能一覧](03_機能一覧.md)、画面の見た目や操作は [画面要件](05-0_画面一覧と共通ルール.md)、表示する文章は [メッセージ一覧](06_メッセージ一覧.md) を参照してください。

## 1. 記録の機能（機能1〜4）

### 1-1. 1件の記録に入れる項目

| 項目 | 必須 | ルール |
|---|---|---|
| 日付 | 必須 | 実際にある日付（2000年1月1日〜2099年12月31日） |
| 種類 | 必須 | 「収入」か「支出」のどちらか |
| カテゴリ | 必須 | 種類に合ったカテゴリから選ぶ（支出なら支出用のカテゴリだけ） |
| 金額 | 必須 | 1円〜9,999,999円の整数（円） |
| メモ | 任意 | 100文字まで |

- 入力のチェックは、画面側と処理側の**両方**で行う（画面側のチェックをすり抜けても、処理側で止めるため）
- メモの前後の空白は取り除いて保存する

### 1-2. 記録の一覧（機能2）

- 選んだ月の記録だけを表示する。最初に開いたときは**今月**を表示する
- 並び順は**日付の新しい順**。同じ日付のときは、あとから登録したものを上にする
- その月の記録が0件のときは、「この月の記録はありません。」と表示する
- 1か月の記録は多くても300件程度を想定し、ページを分けずに全件を表示する

### 1-3. 記録の削除（機能4）

- 削除の前に、確認の窓を出す。「削除する」を押したときだけ削除する
- 削除したデータは元に戻せない

## 2. 月ごとの合計（機能5）

| 表示するもの | 計算のしかた |
|---|---|
| 収入の合計 | 選んだ月の「収入」の金額をすべて足す |
| 支出の合計 | 選んだ月の「支出」の金額をすべて足す |
| 差額 | 収入の合計 − 支出の合計（マイナスになることもある） |

- 記録を登録・修正・削除したら、合計もすぐに計算し直して表示する
- 記録が0件の月は、すべて「0円」と表示する

## 3. カテゴリの機能（機能6〜9）

### 3-1. 1件のカテゴリに入れる項目

| 項目 | 必須 | ルール |
|---|---|---|
| 種類 | 必須 | 「収入用」か「支出用」のどちらか。**登録したあとは変えられない** |
| 名前 | 必須 | 1〜20文字。前後の空白は取り除く。空白だけの名前は登録できない |

### 3-2. カテゴリのルール

- 同じ種類の中で、同じ名前のカテゴリは登録できない
  - 「収入用の『その他』」と「支出用の『その他』」は、種類が違うので両方登録できる
  - **完全に同じ文字のときだけ**、同じ名前とみなす
  - ひらがなとカタカナ、全角と半角、英字の大文字と小文字は、別の名前として扱う（例：「カフェ」「かふぇ」「ｶﾌｪ」は別の名前。「Food」と「food」も別の名前）
- 修正できるのは**名前だけ**。種類は変えられない
  - 理由：すでに記録で使われているカテゴリの種類が変わると、「収入なのに支出用のカテゴリ」という記録ができてしまうため
- 記録で使われているカテゴリを修正するときは、**何件の記録で使われているか**と、**名前を変えるとすべての記録に反映されること**を知らせる（N05）
- 記録で使われているカテゴリは**削除できない**
- 一覧は種類ごと（収入用・支出用）に分けて表示する
- **並び順**は、登録した順。ただし、名前が「**その他**」のカテゴリは**いつも一番下**に表示する
  - 新しく登録したカテゴリは、「その他」のすぐ上に並ぶ
  - カテゴリ一覧画面と、記録入力画面のカテゴリの選択肢は、同じ並び順にする
  - 「その他」の名前を変えた場合は、ほかのカテゴリと同じ扱い（登録した順の位置）になる
- カテゴリが1つもない種類では、その種類の記録を登録できない（記録入力画面でお知らせを表示する）

### 3-3. 最初から入れておくカテゴリ

アプリを使い始めたときに、次のカテゴリを入れておく。あとから修正・削除できる。

| 種類 | カテゴリ |
|---|---|
| 収入用（5件） | 給料、賞与、副業、臨時収入、その他 |
| 支出用（12件） | 食費、外食、日用品、住居費、光熱費、通信費、交通費、医療費、衣服・美容、趣味・娯楽、交際費、その他 |


## 4. 保存するデータ（データ要件）

| データ | 内容 | 想定する量 |
|---|---|---|
| 記録 | 日付・種類・カテゴリ・金額・メモ | 最大1万件程度 |
| カテゴリ | 種類・名前 | 最大100件程度 |

- データを保存する期間は、公開期間が終わるまで（終了後は削除する。[非機能要件](07_非機能要件.md) を参照）
- 本番環境のデータは**お試し用**。最初の状態に戻せるようにする（[非機能要件](07_非機能要件.md) を参照）
- データベースでの保存のしかたは、設計の [ER図](../02_設計/03_ER図.md)・[テーブル定義書](../02_設計/04_テーブル定義書.md) を参照
