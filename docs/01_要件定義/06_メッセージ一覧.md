# メッセージ一覧

[要件定義書（入口）](00_要件定義書.md) に戻る

アプリの画面に表示する文章を、すべてここにまとめます。
画面の資料やプログラムでは、ここの**番号**で呼びます（同じ文章をあちこちに書かないため）。

## 番号の付け方

| 頭の文字 | 種類 | 表示のしかた |
|---|---|---|
| Q | 確認（Question） | 確認の小窓。「OK」「キャンセル」を選ぶ |
| I | 完了のお知らせ（Information） | 画面の上に数秒間表示する |
| N | 状態のお知らせ（Notice） | 一覧などの場所に表示する |
| E | 入力などの間違い（Error） | 入力の間違いは項目のすぐ下、それ以外は画面の上に赤い文字で表示する |
| S | 通信などの問題（System） | 画面の上に赤い文字で表示する |

## Q：確認

| 番号 | 文章 | 出る場面 |
|---|---|---|
| Q01 | この記録を削除しますか？<br>（11月2日　支出　食費　1,200円）<br>削除すると元に戻せません。 | 記録一覧画面で「削除」を押したとき。（ ）の中は、その記録の内容 |
| Q02 | カテゴリ「食費」を削除しますか？<br>削除すると元に戻せません。 | カテゴリ一覧画面で「削除」を押したとき。「 」の中は、そのカテゴリの名前 |

## I：完了のお知らせ

| 番号 | 文章 | 出る場面 |
|---|---|---|
| I01 | 記録を登録しました。 | 記録の登録が成功したとき |
| I02 | 記録を更新しました。 | 記録の修正が成功したとき |
| I03 | 記録を削除しました。 | 記録の削除が成功したとき |
| I04 | カテゴリを登録しました。 | カテゴリの登録が成功したとき |
| I05 | カテゴリを更新しました。 | カテゴリの修正が成功したとき |
| I06 | カテゴリを削除しました。 | カテゴリの削除が成功したとき |

## N：状態のお知らせ

| 番号 | 文章 | 出る場面 |
|---|---|---|
| N01 | この月の記録はありません。 | 記録一覧画面で、表示中の月の記録が0件のとき |
| N02 | カテゴリがありません。カテゴリ画面で登録してください。 | 記録入力画面で、選んだ種類のカテゴリが0件のとき |
| N03 | カテゴリがありません。 | カテゴリ一覧画面で、ある種類のカテゴリが0件のとき |
| N04 | 読み込み中… | データを読み込んでいる間 |

## E：入力などの間違い

| 番号 | 文章 | 出る場面 |
|---|---|---|
| E01 | 日付を入力してください。 | 日付が空のとき |
| E02 | 日付は2000年1月1日から2099年12月31日までの、正しい日付を入力してください。 | ない日付（例：2月30日）や範囲外の日付のとき |
| E03 | 種類を選んでください。 | 種類が選ばれていないとき |
| E04 | カテゴリを選んでください。 | カテゴリが選ばれていないとき |
| E05 | 金額を入力してください。 | 金額が空のとき |
| E06 | 金額は1以上の整数で入力してください。 | 金額が数字でない、小数、0以下のとき |
| E07 | 金額は9,999,999円以下で入力してください。 | 金額が9,999,999より大きいとき |
| E08 | メモは100文字以内で入力してください。 | メモが100文字より多いとき |
| E09 | カテゴリ名を入力してください。 | カテゴリ名が空、または空白だけのとき |
| E10 | カテゴリ名は20文字以内で入力してください。 | カテゴリ名が20文字より多いとき |
| E11 | 同じ名前のカテゴリがすでにあります。 | 同じ種類に同じ名前のカテゴリがあるとき |
| E12 | このカテゴリは記録で使われているため削除できません。 | 記録で使われているカテゴリを削除しようとしたとき |
| E13 | 選んだカテゴリは使えません。もう一度選んでください。 | 選んだカテゴリが削除されていた、または種類が合わないとき |

## S：通信などの問題

| 番号 | 文章 | 出る場面 |
|---|---|---|
| S01 | サーバーとの通信に失敗しました。時間をおいて、もう一度お試しください。 | 処理側とつながらなかったとき |
| S02 | 対象のデータが見つかりません。すでに削除された可能性があります。 | 修正・削除しようとしたデータが、すでになかったとき |
| S03 | ページが見つかりません。 | 存在しないページを開いたとき |
| S04 | 予期しないエラーが発生しました。時間をおいて、もう一度お試しください。 | 上のどれにも当てはまらない問題が起きたとき |
