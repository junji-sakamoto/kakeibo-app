# 課題の条件と使う技術

## 課題の条件（スクールの指示）

1. 画面側（フロントエンド）・処理側（バックエンド）・データベースを、それぞれ作る
2. React・Java・PostgreSQL などは使わず、代わりのものを使う
3. TypeScript は使ってもよい
4. 本番環境（公開先）は、AWS の EC2 と RDS の組み合わせにする
5. 提出は GitHub の URL（アドレス）。main ブランチではなく、作業用ブランチ（develop）で作業する

> 途中で新しい条件に気づいたら、ここに追記する。

## 用語の説明

| 用語 | 意味 |
|---|---|
| フロントエンド（画面側） | ブラウザに表示される画面や見た目の部分 |
| バックエンド（処理側） | 画面から受け取ったデータを保存したり、集計したりする部分 |
| データベース | データを保存しておく場所 |
| GitHub | プログラムを保存・公開できるインターネット上のサービス |
| ブランチ | 作業の枝分かれ。main（本流）を壊さずに作業できる |
| AWS | Amazon のインターネット上のサーバーを借りられるサービス |
| EC2 | AWS で借りるサーバー（パソコンのようなもの） |
| RDS | AWS で借りるデータベース |

## 使う技術

| 部品 | 役割 | 使うもの | 置き換えた元 | フォルダ |
|---|---|---|---|---|
| 画面側（フロントエンド） | 画面・見た目 | Vue.js（ビュー・ジェイエス） | React | `frontend/` |
| 処理側（バックエンド） | データの受け付け・保存・集計 | Node.js（ノード・ジェイエス）＋ Express（エクスプレス） | Java | `backend/` |
| データベース | データの保存 | MySQL（マイ・エスキューエル） | PostgreSQL | `database/` |

- プログラムの言語は JavaScript（ジャバスクリプト）に統一する
  - TypeScript は使ってよいが、分かりやすさを優先して使わない
  - JavaScript と Java は名前が似ているが、まったく別の言語
- Tailwind CSS は使わない（以前の指示にあったため、念のため）
- プログラムのフォルダ名は英語にする（日本語の名前だとトラブルが起きやすいため）

## 本番環境の組み合わせ

```
[ブラウザ] → [EC2：画面側 ＋ 処理側] → [RDS：MySQL]
```

## 条件を満たしているかの確認

| 条件 | どう満たすか |
|---|---|
| 3つの部品を作る | `frontend/`・`backend/`・`database/` にフォルダを分けて作る |
| React・Java・PostgreSQL を使わない | Vue.js・Node.js・MySQL に置き換える |
| EC2 と RDS の組み合わせ | EC2 で画面側と処理側を動かし、RDS の MySQL につなぐ |
| 作業用ブランチで作業する | `develop` ブランチで作業する |
