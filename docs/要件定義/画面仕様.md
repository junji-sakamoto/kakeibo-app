# 画面仕様

[要件定義書（入口）](../要件定義書.md) に戻る

どんな画面があり、それぞれに何を表示し、ボタンを押すと何が起きるかをまとめます。
ルールのくわしい内容は [機能要件](機能要件.md)、表示する文章は [メッセージ一覧](メッセージ一覧.md) を参照してください。

> 配置図は「どこに何があるか」を示すための簡単な絵です。色や大きさなどの細かい見た目は、設計で決めます。

## 1. 画面の一覧

| 番号 | 画面の名前 | 役割 | 関係する機能 |
|---|---|---|---|
| 画面1 | 記録一覧画面 | 最初に開く画面。月ごとの記録と合計を見る | 機能2・4・5 |
| 画面2 | 記録入力画面 | 記録を登録・修正する | 機能1・3 |
| 画面3 | カテゴリ一覧画面 | カテゴリを見る・削除する | 機能7・9 |
| 画面4 | カテゴリ入力画面 | カテゴリを登録・修正する | 機能6・8 |

- 登録と修正は、同じ入力画面を使う（見出しとボタンの文字だけを変える）
- 削除の確認は、画面ではなく小窓（ブラウザの確認ダイアログ）で行う

## 2. 画面のつながり（画面遷移）

画面のつながりは、基本設計の [画面遷移図](../設計/画面遷移図.md) にまとめています。

## 3. すべての画面に共通すること

### 3-1. 画面の上の部分（ヘッダー）

```
┌──────────────────────────────────────────┐
│ 家計簿                    [記録] [カテゴリ] │
└──────────────────────────────────────────┘
```

| 部品 | 動き |
|---|---|
| 「家計簿」（アプリの名前） | 押すと、画面1 記録一覧画面に移る |
| 「記録」 | 押すと、画面1 記録一覧画面に移る。画面1・2を開いているときは目立つ色にする |
| 「カテゴリ」 | 押すと、画面3 カテゴリ一覧画面に移る。画面3・4を開いているときは目立つ色にする |

### 3-2. 共通の表示ルール

| 内容 | ルール |
|---|---|
| 言葉 | 画面の文字・メッセージはすべて日本語 |
| 金額 | 3けたごとにカンマを付け、後ろに「円」を付ける（例：1,000円）。マイナスは「-1,000円」 |
| 日付 | 「2026年11月2日」の形で表示する。一覧では「11月2日（月）」のように曜日も付ける |
| 収入と支出の見分け | 収入は青系、支出は赤系の色にする。色が分かりにくい人のために、**必ず「収入」「支出」の文字も表示する** |
| 完了のお知らせ | 保存・削除が成功したら、画面の上に完了のメッセージを数秒間表示する |
| エラーのお知らせ | 入力の間違いは、その項目のすぐ下に赤い文字で表示する。通信の失敗などは画面の上に表示する |
| 読み込み中 | データを読み込んでいる間は「読み込み中…」と表示する |
| 二重の操作の防止 | 「保存」を押してから結果が出るまでは、ボタンを押せないようにする（同じ記録が2件できるのを防ぐ） |
| 存在しないページ | 「ページが見つかりません。」と表示し、記録一覧画面へのリンクを出す |

## 4. 画面1 記録一覧画面

### 4-1. 目的

選んだ月の記録と合計を確認し、記録の登録・修正・削除を始める画面。アプリを開くと最初に表示される。

### 4-2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                                [記録] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│     [◀ 前の月]      2026年11月      [次の月 ▶] [今月]  │ ← ① 月の切り替え
│                                                      │
│  ┌────────────┐ ┌────────────┐ ┌────────────┐         │
│  │ 収入        │ │ 支出        │ │ 差額        │         │ ← ② 月の合計
│  │ 250,000円  │ │ 180,000円  │ │ 70,000円   │         │
│  └────────────┘ └────────────┘ └────────────┘         │
│                                                      │
│                                          [＋ 登録]    │ ← ③ 登録ボタン
│                                                      │
│  日付        種類  カテゴリ  金額        メモ           │ ← ④ 記録の一覧
│  ─────────────────────────────────────────────────── │
│  11月2日(月)  支出  食費      1,200円   ランチ [修正][削除]│
│  11月1日(日)  収入  給料    250,000円         [修正][削除]│
│  11月1日(日)  支出  交通費      500円   バス   [修正][削除]│
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 4-3. 表示する項目

| 番号 | 項目 | 内容 |
|---|---|---|
| ① | 表示中の月 | 「2026年11月」の形。最初は今月 |
| ② | 収入の合計 | 表示中の月の収入の合計 |
| ② | 支出の合計 | 表示中の月の支出の合計 |
| ② | 差額 | 収入の合計 − 支出の合計。マイナスのときは赤系の色にする |
| ④ | 日付 | 「11月2日（月）」の形 |
| ④ | 種類 | 「収入」または「支出」（色分けもする） |
| ④ | カテゴリ | カテゴリの名前 |
| ④ | 金額 | 「1,200円」の形。右にそろえる |
| ④ | メモ | 長いときは途中で切って「…」を付ける |

- 一覧の並び順：日付の新しい順。同じ日付は、あとから登録したものを上
- 記録が0件のとき：一覧の代わりに「この月の記録はありません。」（N01）と表示する

### 4-4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「◀ 前の月」 | 1か月前の記録と合計を表示する |
| 「次の月 ▶」 | 1か月後の記録と合計を表示する |
| 「今月」 | 今月の記録と合計を表示する |
| 「＋ 登録」 | 画面2 記録入力画面を「登録」の状態で開く |
| 「修正」 | その記録の内容を入れた状態で、画面2 記録入力画面を「修正」の状態で開く |
| 「削除」 | 確認の小窓（Q01）を出す。「OK」なら削除して完了のメッセージ（I03）を出し、一覧と合計を表示し直す。「キャンセル」なら何もしない |

- 記録入力画面から戻ってきたときは、**直前に見ていた月**を表示する
  - ただし、保存した記録の日付が別の月のときは、**保存した記録の月**を表示する

## 5. 画面2 記録入力画面

### 5-1. 目的

記録を1件登録する、または登録した記録を直す画面。

### 5-2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                                [記録] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  記録の登録                     ← 修正のときは「記録の修正」│
│                                                      │
│  日付 ＊      [ 2026/11/02  📅 ]                       │
│                                                      │
│  種類 ＊      (●) 支出   ( ) 収入                      │
│                                                      │
│  カテゴリ ＊  [ 選んでください        ▼ ]               │
│                                                      │
│  金額 ＊      [            ] 円                        │
│               金額を入力してください。 ← エラーの表示例   │
│                                                      │
│  メモ         [                              ]        │
│               （100文字まで）                          │
│                                                      │
│               [ 保存する ]   [ 戻る ]                  │
│                         ← 修正のときは「更新する」       │
│  ＊は必須の項目です                                     │
└──────────────────────────────────────────────────────┘
```

### 5-3. 入力する項目

| 項目 | 必須 | 入力のしかた | 登録のときの最初の値 | チェックの内容（間違いのときのメッセージ） |
|---|---|---|---|---|
| 日付 | 必須 | 日付の入力欄（カレンダーから選べる） | 今日 | 未入力（E01）、ない日付・範囲外（E02） |
| 種類 | 必須 | 「支出」「収入」のどちらかを選ぶ | 支出 | 未選択（E03） |
| カテゴリ | 必須 | 選択肢から選ぶ。選んだ種類のカテゴリだけが出る | 未選択 | 未選択（E04）、使えないカテゴリ（E13） |
| 金額 | 必須 | 数字を入力する | 空 | 未入力（E05）、整数でない・1未満（E06）、上限より大きい（E07） |
| メモ | 任意 | 文字を入力する | 空 | 100文字より多い（E08） |

- 修正のときは、すべての項目に、登録してある値を入れた状態で開く
- **種類を切り替えると**、カテゴリの選択肢がその種類のものに変わり、選んでいたカテゴリは「未選択」に戻る
- 選んだ種類のカテゴリが1つもないときは、カテゴリ欄に「カテゴリがありません。カテゴリ画面で登録してください。」（N02）と表示し、保存できないようにする

### 5-4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「保存する」（登録のとき）／「更新する」（修正のとき） | 入力をチェックする。間違いがあれば、その項目の下にメッセージを出し、保存しない。間違いがなければ保存し、画面1に戻って完了のメッセージ（登録：I01、修正：I02）を出す |
| 「戻る」 | 保存せずに画面1に戻る |

- 修正しようとした記録が、すでに削除されていたとき：「対象のデータが見つかりません。すでに削除された可能性があります。」（S02）を出し、画面1に戻る

## 6. 画面3 カテゴリ一覧画面

### 6-1. 目的

カテゴリを種類ごとに確認し、カテゴリの登録・修正・削除を始める画面。

### 6-2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                                [記録] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  カテゴリ                                  [＋ 登録]   │
│                                                      │
│  ■ 支出用                                             │
│  ─────────────────────────────────────────            │
│  食費                              [修正] [削除]       │
│  日用品                            [修正] [削除]       │
│  交通費                            [修正] [削除]       │
│  光熱費                            [修正] [削除]       │
│  その他                            [修正] [削除]       │
│                                                      │
│  ■ 収入用                                             │
│  ─────────────────────────────────────────            │
│  給料                              [修正] [削除]       │
│  その他                            [修正] [削除]       │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 6-3. 表示する項目

| 項目 | 内容 |
|---|---|
| 支出用のカテゴリ | 支出用のカテゴリの名前を、登録した順に並べる |
| 収入用のカテゴリ | 収入用のカテゴリの名前を、登録した順に並べる |

- ある種類のカテゴリが0件のとき：その種類の所に「カテゴリがありません。」（N03）と表示する

### 6-4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「＋ 登録」 | 画面4 カテゴリ入力画面を「登録」の状態で開く |
| 「修正」 | そのカテゴリの内容を入れた状態で、画面4 カテゴリ入力画面を「修正」の状態で開く |
| 「削除」 | 確認の小窓（Q02）を出す。「OK」なら削除して完了のメッセージ（I06）を出し、一覧を表示し直す。記録で使われているカテゴリのときは削除せず、「このカテゴリは記録で使われているため削除できません。」（E12）を出す |

## 7. 画面4 カテゴリ入力画面

### 7-1. 目的

カテゴリを1件登録する、または登録したカテゴリの名前を直す画面。

### 7-2. 配置図

```
┌──────────────────────────────────────────────────────┐
│ 家計簿                                [記録] [カテゴリ] │
├──────────────────────────────────────────────────────┤
│                                                      │
│  カテゴリの登録              ← 修正のときは「カテゴリの修正」│
│                                                      │
│  種類 ＊      (●) 支出用   ( ) 収入用                   │
│               ← 修正のときは選べない（表示だけ）          │
│                                                      │
│  名前 ＊      [                    ]                   │
│               （20文字まで）                           │
│                                                      │
│               [ 保存する ]   [ 戻る ]                  │
│                         ← 修正のときは「更新する」       │
│  ＊は必須の項目です                                     │
└──────────────────────────────────────────────────────┘
```

### 7-3. 入力する項目

| 項目 | 必須 | 入力のしかた | 登録のときの最初の値 | チェックの内容（間違いのときのメッセージ） |
|---|---|---|---|---|
| 種類 | 必須 | 「支出用」「収入用」のどちらかを選ぶ。**修正のときは変えられない** | 支出用 | 未選択（E03） |
| 名前 | 必須 | 文字を入力する | 空 | 未入力・空白だけ（E09）、20文字より多い（E10）、同じ種類に同じ名前がある（E11） |

### 7-4. ボタンと操作

| 部品 | 押したときの動き |
|---|---|
| 「保存する」（登録のとき）／「更新する」（修正のとき） | 入力をチェックする。間違いがあれば、その項目の下にメッセージを出し、保存しない。間違いがなければ保存し、画面3に戻って完了のメッセージ（登録：I04、修正：I05）を出す |
| 「戻る」 | 保存せずに画面3に戻る |

- 修正しようとしたカテゴリが、すでに削除されていたとき：（S02）を出し、画面3に戻る
