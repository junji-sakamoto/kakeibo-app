# 機能要件（機能に関する決まりごと）

[要件定義書（入口）](../要件定義書.md) に戻る

アプリにどんな機能があり、それぞれどんなルールで動くかをまとめます。
画面の見た目や操作は [画面仕様](画面仕様.md)、表示する文章は [メッセージ一覧](メッセージ一覧.md) を参照してください。

## 1. 機能の一覧

| 番号 | 区分 | 機能 | 内容 | 使う画面 |
|---|---|---|---|---|
| 機能1 | 記録 | 記録の登録 | 収入・支出を1件登録する | 記録入力画面 |
| 機能2 | 記録 | 記録の一覧 | 選んだ月の記録を一覧で見る | 記録一覧画面 |
| 機能3 | 記録 | 記録の修正 | 登録した記録を直す | 記録入力画面 |
| 機能4 | 記録 | 記録の削除 | 登録した記録を消す | 記録一覧画面 |
| 機能5 | 集計 | 月ごとの合計 | 選んだ月の収入合計・支出合計・差額を表示する | 記録一覧画面 |
| 機能6 | カテゴリ | カテゴリの登録 | 新しいカテゴリを追加する | カテゴリ入力画面 |
| 機能7 | カテゴリ | カテゴリの一覧 | カテゴリを一覧で見る | カテゴリ一覧画面 |
| 機能8 | カテゴリ | カテゴリの修正 | カテゴリの名前を直す | カテゴリ入力画面 |
| 機能9 | カテゴリ | カテゴリの削除 | カテゴリを消す | カテゴリ一覧画面 |

作る順番：記録（機能1〜4）→ 月ごとの合計（機能5）→ カテゴリ（機能6〜9）

## 2. 記録の機能（機能1〜4）

### 2-1. 1件の記録に入れる項目

| 項目 | 必須 | ルール |
|---|---|---|
| 日付 | 必須 | 実際にある日付（2000年1月1日〜2099年12月31日） |
| 種類 | 必須 | 「収入」か「支出」のどちらか |
| カテゴリ | 必須 | 種類に合ったカテゴリから選ぶ（支出なら支出用のカテゴリだけ） |
| 金額 | 必須 | 1円〜9,999,999円の整数（円） |
| メモ | 任意 | 100文字まで |

- 入力のチェックは、画面側と処理側の**両方**で行う（画面側のチェックをすり抜けても、処理側で止めるため）
- メモの前後の空白は取り除いて保存する

### 2-2. 記録の一覧（機能2）

- 選んだ月の記録だけを表示する。最初に開いたときは**今月**を表示する
- 並び順は**日付の新しい順**。同じ日付のときは、あとから登録したものを上にする
- その月の記録が0件のときは、「この月の記録はありません。」と表示する
- 1か月の記録は多くても300件程度を想定し、ページを分けずに全件を表示する

### 2-3. 記録の削除（機能4）

- 削除の前に、確認の小窓を出す。「OK」を押したときだけ削除する
- 削除したデータは元に戻せない

## 3. 月ごとの合計（機能5）

| 表示するもの | 計算のしかた |
|---|---|
| 収入の合計 | 選んだ月の「収入」の金額をすべて足す |
| 支出の合計 | 選んだ月の「支出」の金額をすべて足す |
| 差額 | 収入の合計 − 支出の合計（マイナスになることもある） |

- 記録を登録・修正・削除したら、合計もすぐに計算し直して表示する
- 記録が0件の月は、すべて「0円」と表示する

## 4. カテゴリの機能（機能6〜9）

### 4-1. 1件のカテゴリに入れる項目

| 項目 | 必須 | ルール |
|---|---|---|
| 種類 | 必須 | 「収入用」か「支出用」のどちらか。**登録したあとは変えられない** |
| 名前 | 必須 | 1〜20文字。前後の空白は取り除く。空白だけの名前は登録できない |

### 4-2. カテゴリのルール

- 同じ種類の中で、同じ名前のカテゴリは登録できない
  - 「収入用の『その他』」と「支出用の『その他』」は、種類が違うので両方登録できる
  - **完全に同じ文字のときだけ**、同じ名前とみなす
  - ひらがなとカタカナ、全角と半角、英字の大文字と小文字は、別の名前として扱う（例：「カフェ」「かふぇ」「ｶﾌｪ」は別の名前。「Food」と「food」も別の名前）
- 修正できるのは**名前だけ**。種類は変えられない
  - 理由：すでに記録で使われているカテゴリの種類が変わると、「収入なのに支出用のカテゴリ」という記録ができてしまうため
- 記録で使われているカテゴリは**削除できない**
- 一覧は種類ごと（収入用・支出用）に分けて、登録した順に表示する
- カテゴリが1つもない種類では、その種類の記録を登録できない（記録入力画面でお知らせを表示する）

### 4-3. 最初から入れておくカテゴリ

アプリを使い始めたときに、次のカテゴリを入れておく。あとから修正・削除できる。

| 種類 | カテゴリ |
|---|---|
| 収入用 | 給料、その他 |
| 支出用 | 食費、日用品、交通費、光熱費、その他 |

## 5. 保存するデータ（データ要件）

| データ | 内容 | 想定する量 |
|---|---|---|
| 記録 | 日付・種類・カテゴリ・金額・メモ | 最大1万件程度 |
| カテゴリ | 種類・名前 | 最大100件程度 |

- データを保存する期間は、公開期間が終わるまで（終了後は削除する。[非機能要件](非機能要件.md) を参照）
- 本番環境のデータは**お試し用**。最初の状態に戻せるようにする（[非機能要件](非機能要件.md) を参照）
