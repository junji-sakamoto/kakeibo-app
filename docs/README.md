# 資料の入口

家計簿アプリ（kakeibo-app）の資料をまとめたフォルダです。
まずこのページを読み、必要な資料を開いてください。

## 資料の一覧

| 資料 | 内容 | 状態 |
|---|---|---|
| [課題の条件と使う技術](conditions.md) | スクールの課題の条件と、それに合わせて選んだ技術 | 作成済み |
| [要件定義](requirements.md) | アプリに入れる機能と、そのルール | 作成済み |
| 設計 | 画面・データベース・API の設計 | これから |

## 資料の書き方のルール

- 同じ内容は1か所にだけ書き、ほかの資料からはリンクで参照する
- 決まっていないことは「あとで決めること」に書いておく
