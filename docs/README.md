# 資料の入口

家計簿アプリ（kakeibo-app）の資料をまとめたフォルダです。
まずこのページを読み、必要な資料を開いてください。

## 資料の一覧

| 資料 | 内容 | 状態 |
|---|---|---|
| [課題の条件と使う技術](課題の条件と使う技術.md) | スクールの課題の条件・選んだ技術・用語の説明 | 作成済み |
| [要件定義書](要件定義書.md) | 目的・利用の流れ・機能の決まりごと・機能以外の決まりごと | 作成済み |
| [スケジュール](スケジュール.md) | 作業の順番と進み具合 | 作成済み |
| 設計書 | 画面・データベース・やりとりの決まりごと（API）・全体の組み立て | これから |

## 資料の書き方のルール

- 同じ内容は1か所にだけ書き、ほかの資料からはリンクで参照する
- 決まっていないことは「あとで決めること」に書いておく
- 資料のファイル名と本文は、できるだけ日本語で書く
  - ただし `README.md` は、GitHub が最初に表示するファイルの決まった名前なので英語のままにする
