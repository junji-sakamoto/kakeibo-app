## 1. データベース全体の決まり

| 項目 | 決めたこと | 理由 |
|---|---|---|
| データベースの名前 | `kakeibo` | — |
| 文字コード | `utf8mb4` | 日本語や絵文字を含む、すべての文字を保存できるようにするため |
| 文字の比べ方（照合順序） | `utf8mb4_bin` | **完全に同じ文字だけを同じ**とみなすため。「カフェ」と「かふぇ」、「ハス」と「バス」、全角「カフェ」と半角「ｶﾌｪ」、「Food」と「food」はすべて別の名前になる（[機能要件](../01_要件定義/04_機能要件.md) のカテゴリのルール） |

### 文字の比べ方を決めた経緯

最初は `utf8mb4_ja_0900_as_cs_ks`（日本語用の比べ方）にしていました。しかし、実際にデータベースを動かして確かめたところ、**全角「カフェ」と半角「ｶﾌｪ」が同じ名前と判断される**ことが分かりました（2026年11月2日）。
要件の「全角と半角は別の名前として扱う」を守るため、`utf8mb4_bin` に変えました。
| テーブルの種類（ストレージエンジン） | `InnoDB` | 外部キーと、まとめて取り消せる処理（トランザクション）が使えるため |

## 2. 型の説明

| 型 | 意味 |
|---|---|
| INT UNSIGNED | 0以上の整数（約42億まで） |
| VARCHAR(n) | n 文字までの文字 |
| DATE | 日付（年・月・日） |
| DATETIME | 日時（年・月・日・時・分・秒） |

## 3. categories（カテゴリ）

| 項目 | 名前 | 型 | 空を許す | 最初の値 | 決まり |
|---|---|---|---|---|---|
| 番号 | id | INT UNSIGNED | × | 自動で付く番号 | 主キー |
| 種類 | type | VARCHAR(10) | × | — | `income`（収入用）か `expense`（支出用）だけ |
| 名前 | name | VARCHAR(20) | × | — | 1〜20文字。空の文字は不可 |
| 登録した日時 | created_at | DATETIME | × | 登録した日時 | — |
| 最後に更新した日時 | updated_at | DATETIME | × | 登録した日時 | 更新すると自動で今の日時に変わる |

| 決まりの名前 | 種類 | 内容 |
|---|---|---|
| PRIMARY | 主キー | id |
| uq_categories_type_name | 同じ値を許さない（ユニーク） | 同じ種類（type）の中で、同じ名前（name）を許さない |
| chk_categories_type | チェック | type は `income` か `expense` だけ |
| chk_categories_name | チェック | name は空の文字を許さない |

## 4. records（記録）

| 項目 | 名前 | 型 | 空を許す | 最初の値 | 決まり |
|---|---|---|---|---|---|
| 番号 | id | INT UNSIGNED | × | 自動で付く番号 | 主キー |
| カテゴリの番号 | category_id | INT UNSIGNED | × | — | categories の id を指す（外部キー） |
| 日付 | recorded_on | DATE | × | — | 2000-01-01 〜 2099-12-31 |
| 金額 | amount | INT UNSIGNED | × | — | 1 〜 9,999,999 |
| メモ | memo | VARCHAR(100) | × | 空の文字 | 100文字まで |
| 登録した日時 | created_at | DATETIME | × | 登録した日時 | — |
| 最後に更新した日時 | updated_at | DATETIME | × | 登録した日時 | 更新すると自動で今の日時に変わる |

| 決まりの名前 | 種類 | 内容 |
|---|---|---|
| PRIMARY | 主キー | id |
| fk_records_category | 外部キー | category_id は categories の id を指す。**記録で使われているカテゴリは削除できない**（ON DELETE RESTRICT） |
| idx_records_recorded_on | 索引（インデックス） | 日付で探すのを速くする（月ごとの一覧・合計で使うため） |
| chk_records_amount | チェック | amount は 1〜9,999,999 |
| chk_records_recorded_on | チェック | recorded_on は 2000-01-01〜2099-12-31 |

### メモを「空を許さない（最初の値は空の文字）」にした理由

メモがないことを「空の文字（''）」の1通りだけで表すためです。「NULL（値がない）」も許すと、「空の文字」と「NULL」の2通りができて、プログラムでの扱いがややこしくなります。
