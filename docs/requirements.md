# 要件定義

アプリに入れる機能と、そのルールをまとめます。
使う技術は [課題の条件と使う技術](conditions.md) を参照してください。

## 1. アプリの目的

毎日の収入と支出を記録し、月ごとにお金の流れを確認できるようにする。

## 2. 使う人

- 自分1人で使う（ログイン機能は作らない）
- スクールの講師が確認できるように、本番環境は**誰でも見られる状態で公開する**
  - そのため、本番環境には本物の家計のデータは入れず、**お試し用のデータだけ**を入れる

## 3. 機能の一覧

| 番号 | 区分 | 機能 | 内容 |
|---|---|---|---|
| F1 | 記録 | 記録の登録 | 収入・支出を1件登録する |
| F2 | 記録 | 記録の一覧 | 登録した記録を一覧で見る |
| F3 | 記録 | 記録の修正 | 登録した記録を直す |
| F4 | 記録 | 記録の削除 | 登録した記録を消す |
| F5 | 集計 | 月ごとの合計 | 選んだ月の収入合計・支出合計・差額（残り）を表示する |
| F6 | カテゴリ | カテゴリの登録 | 新しいカテゴリを追加する |
| F7 | カテゴリ | カテゴリの一覧 | カテゴリを一覧で見る |
| F8 | カテゴリ | カテゴリの修正 | カテゴリの名前を直す |
| F9 | カテゴリ | カテゴリの削除 | カテゴリを消す |

作る順番：記録（F1〜F4）→ 月ごとの合計（F5）→ カテゴリ（F6〜F9）

## 4. 記録のルール

1件の記録には、次の項目を入れます。

| 項目 | 必須 | ルール |
|---|---|---|
| 日付 | 必須 | 年・月・日 |
| 種類 | 必須 | 「収入」か「支出」のどちらか |
| カテゴリ | 必須 | 種類に合ったカテゴリから選ぶ |
| 金額 | 必須 | 1円以上の整数（円） |
| メモ | 任意 | 100文字まで |

- 一覧は日付の新しい順に並べる
- 一覧は月を選んで、その月の記録だけを表示する
- 削除するときは「本当に削除しますか？」と確認する

## 5. 月ごとの合計のルール

- 選んだ月の「収入の合計」「支出の合計」「差額（収入 − 支出）」を表示する
- 記録の一覧と同じ画面に表示する

## 6. カテゴリのルール

- カテゴリは「収入用」と「支出用」に分ける
  - 支出を登録するときは、支出用のカテゴリだけを選べる
- 同じ種類の中で、同じ名前のカテゴリは登録できない
- カテゴリ名は1〜20文字
- 記録で使われているカテゴリは**削除できない**
  - 「このカテゴリは記録で使われているため削除できません」と表示する
- アプリを使い始めたときに、次のカテゴリを最初から入れておく（あとから修正・削除できる）

| 種類 | 最初から入れておくカテゴリ |
|---|---|
| 収入 | 給料、その他 |
| 支出 | 食費、日用品、交通費、光熱費、その他 |

## 7. 作らないもの

- ログイン機能（使うのは自分1人のため）
- カテゴリ別の集計・グラフ（余裕があれば、あとで追加を検討する）

## 8. あとで決めること

- 文字数・金額の上限などの細かい数字（今の数字は仮。設計で見直してよい）
