## 基本設計とは

[要件定義書](../要件定義書.md) で決めた「**何を作るか**」をもとに、「**どう作るか**」の大きな形を決める段階です。
ここでは、**どの技術を使っても変わらない部分**（画面のつながり・データの形・データの流れ・見た目）を決めます。
技術に合わせた細かい設計（テーブルの細かい定義・API・サーバーの組み立て）は、技術選定のあとの「詳細設計」で行います。

## この基本設計書の読み方

この資料は「入口」です。くわしい内容は、次の資料に分けて書いています。

| 番号 | 資料 | 内容 | 状態 |
|---|---|---|---|
| 1 | [画面遷移図](画面遷移図.md) | どの画面から、どの画面へ移るか | 確認中 |
| 2 | ER図 | どんなデータを、どんな関係で保存するか | これから |
| 3 | データの流れの図 | 操作したとき、データがどこを通って動くか | これから |
| 4 | 画面設計 | 色・大きさ・文字の大きさなどの見た目 | これから |
| 5 | 技術選定書 | 上の設計をもとに、使う技術を正式に決める | これから |

## 図の書き方について

図は **Mermaid（マーメイド）** という書き方で作っています。

- 文字で書くだけで図になるので、図を直すのが簡単
- GitHub では、自動できれいな図として表示される
- VS Code で図として見るには、拡張機能「Markdown Preview Mermaid Support」が必要
