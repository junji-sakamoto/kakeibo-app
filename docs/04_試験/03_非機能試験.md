[試験計画書（入口）](00_試験計画書.md) に戻る

[非機能要件](../01_要件定義/07_非機能要件.md) の確認項目と結果です。
**AWS に公開して初めて確かめられるもの**は、「時期」を「公開後」とし、公開したあとに結果を書きます。

- 実施日：2026年11月3日（「今」の項目）
- 結果：「今」の項目は**すべて合格**。「公開後」の項目は未実施

## 2. 性能・拡張性

| 確認項目 | 時期 | 確かめ方 | 結果 |
|---|---|---|---|
| 記録1万件・1人で、一覧と合計が3秒以内 | 今 | 性能の試験（`npm run perf`）。1か月に810件ある月の一覧と合計 | **合格**（0.14秒） |
| 記録1万件・10人が同時に、一覧と合計が3秒以内 | 今 | 同上。違う月を10人が同時に | **合格**（いちばん遅いもので0.40秒） |
| 10人が同時に、カテゴリの一覧・記録の登録が3秒以内 | 今 | 同上 | **合格**（0.07秒・0.16秒） |
| 本番環境（EC2・RDS）でも3秒以内 | 公開後 | 本番環境で同じ性能の試験を行う | 未実施 |

- 処理側の速さを測る試験です。画面の表示にかかる時間は、E2E 試験の中で、どの画面も数秒以内に表示されることで確かめています
- 試験の数値は、2026年11月3日に自分のパソコン（Docker の MySQL）で測ったものです

| 大きすぎる本文（10KB 超）を受け付けない | 今 | API 試験「大きすぎる本文」 | **合格** |
